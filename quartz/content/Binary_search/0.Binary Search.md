## Brute-force approach

Scan the sorted array from left to right and compare each value with the target. Return the matching index, or `-1` after the scan finishes.

**Time complexity:** $O(n)$

**Space complexity:** $O(1)$

## Optimal approach

Binary search keeps a search interval and discards half of it after every comparison. If the middle value is smaller than the target, move right; otherwise move left.

**Time complexity:** $O(log n)$

**Space complexity:** $O(1)$
