## Problem

Ship packages in their given order within a fixed number of days. Find the minimum ship capacity that can transport all packages.

**LeetCode:** [Capacity To Ship Packages Within D Days - LeetCode 1011](https://leetcode.com/problems/capacity-to-ship-packages-within-d-days/)

## Brute-force approach

Try every capacity from the heaviest package to the sum of all package weights. For each capacity, scan the packages in order and count how many days are required. Return the first capacity that needs no more than the allowed number of days.

**Time complexity:** $O(n * S)$, where $S$ is the sum of all package weights.

**Space complexity:** $O(1)$

## Optimal approach: binary search on capacity

For a fixed capacity, the required number of days is monotonic. A larger capacity never needs more days than a smaller capacity, so binary search the capacity range.

1. The lower bound is the heaviest package.
2. The upper bound is the total weight.
3. Greedily load packages until the next package would exceed the trial capacity.
4. If the required days are within the limit, reduce the capacity; otherwise increase it.

**Time complexity:** $O(n log S)$

**Space complexity:** $O(1)$
