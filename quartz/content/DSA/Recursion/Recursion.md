
-> **Function calling itself until specific condition meets is  called recursion** 
-  uses  Recursive stack and  follows   LIFO 

 ### Steps in  recursion 
-  Define Base case
- Define recursive case 
- Ensure  the recursion terminates
- combine the solution 
 
 ### Application of  Recursion
   
- Tree and Graph Traversal
- Sorting Algorithm 
- Divide  and Conquer
- Fractal Generation
- Backtracking 
- Memoization
