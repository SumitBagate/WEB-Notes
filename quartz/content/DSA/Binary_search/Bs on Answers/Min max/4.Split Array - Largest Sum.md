## Problem

Split an array into a fixed number of contiguous subarrays so that the largest subarray sum is as small as possible.

**LeetCode:** [Split Array Largest Sum - LeetCode 410](https://leetcode.com/problems/split-array-largest-sum/)

## Brute-force approach

Try every possible maximum subarray sum from the largest element to the total array sum. For each candidate, greedily create a new subarray whenever adding the next element would exceed the candidate. Return the first candidate that needs no more than the required number of parts.

**Time complexity:** $O(n * S)$, where $S$ is the total sum.

**Space complexity:** $O(1)$

## Optimal approach: binary search on the answer

The feasibility condition is monotonic. If the array can be split with maximum sum `x`, it can also be split with any larger maximum sum. Binary search for the smallest feasible value.

1. Set `low` to the largest element and `high` to the total sum.
2. Count the parts required for the midpoint limit.
3. If the count is too large, increase the limit.
4. Otherwise, keep the answer and search the smaller half.

**Time complexity:** $O(n log S)$

**Space complexity:** $O(1)$
