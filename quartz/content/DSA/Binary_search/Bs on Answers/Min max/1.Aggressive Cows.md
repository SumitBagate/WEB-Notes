## Problem

Given stall positions and a number of cows, place every cow in a different stall so that the minimum distance between any two cows is as large as possible.

**Practice link:** [Aggressive Cows - GeeksforGeeks](https://www.geeksforgeeks.org/problems/aggressive-cows/1)

## Brute-force approach

Try every possible minimum distance from the smallest useful distance to the largest stall gap. For each candidate distance, greedily place cows from left to right and check whether all cows can be placed. Keep the largest feasible distance.

The placement check is greedy because, for a fixed distance, placing each cow in the earliest possible stall leaves the most room for the remaining cows.

**Time complexity:** $O((maxPosition - minPosition) * n)$

**Space complexity:** $O(1)$

## Optimal approach: binary search on the answer

The predicate is monotonic: if a distance is feasible, every smaller distance is feasible; if a distance is not feasible, every larger distance is also not feasible. Binary search the distance range and use the greedy placement check for each midpoint.

1. Sort the stall positions.
2. Set the search range from `1` to `lastStall - firstStall`.
3. Check whether the midpoint distance can place all cows.
4. If it works, save it and search for a larger distance; otherwise search the smaller half.

**Time complexity:** $O(n log(maxPosition - minPosition))$ after sorting.

**Space complexity:** $O(1)$ auxiliary space, excluding sorting space.
